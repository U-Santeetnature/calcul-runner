# Calcul Runner

Jeu éducatif de calcul mental en français, jouable sur ordinateur et Android depuis GitHub Pages.

- 7 niveaux progressifs
- 70 calculs aléatoires
- 5 cœurs et chrono
- record local
- sprites du coureur et de l’obstacle intégrés
- musique instrumentale par défaut et choix d’un fichier audio local
